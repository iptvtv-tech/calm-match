    Skill map

    Each bar is how sure the engine is that the skill is learned. A skill opens once the one above it passes the first mark (60%). It counts as learned at the second mark (90%).

    Rules in use

    Within a game: 3 first-try matches in a row adds an answer choice. 2 misses on one turn shows a dashed outline on the right answer and removes a choice next turn. Between sessions: a game where fewer than half the turns were right first time is flagged, and next time the engine practises the skill before it first. Every session starts with the strongest game and ends on something familiar. The plan is fixed once a session starts.
