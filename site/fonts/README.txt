Self-hosted fonts (keeps visitors' details away from Google). The site works without them, using Verdana instead.

Put these files in this folder, with exactly these names:
  atkinson-hyperlegible-400.woff2   (Atkinson Hyperlegible, regular)
  atkinson-hyperlegible-700.woff2   (Atkinson Hyperlegible, bold)
  lexend-600.woff2                  (Lexend, weight 600, used for headings)
     or lexend-variable.woff2 (one file with all weights), if you have that instead

Quick downloads (google-webfonts-helper, latin, woff2; free under the SIL Open Font License):
  https://gwfh.mranftl.com/api/fonts/atkinson-hyperlegible?download=zip&subsets=latin&variants=regular,700&formats=woff2
  https://gwfh.mranftl.com/api/fonts/lexend?download=zip&subsets=latin&variants=600&formats=woff2
Unzip, rename the files to the names above, and keep this folder when you copy in a new version of the site.
