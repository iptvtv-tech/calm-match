Optional: self-hosted fonts. The site works without them (it falls back to Verdana / system fonts).

Put these three files in this folder, with exactly these names:
  atkinson-hyperlegible-400.woff2   (Atkinson Hyperlegible, Regular, latin)
  atkinson-hyperlegible-700.woff2   (Atkinson Hyperlegible, Bold, latin)
  lexend-variable.woff2             (Lexend, variable weight, latin)

Free download (SIL Open Font License): https://gwfh.mranftl.com/fonts  (search each font, pick "latin", download woff2)
or https://fontsource.org/fonts/atkinson-hyperlegible and https://fontsource.org/fonts/lexend
Self-hosting keeps visitors' IP addresses away from Google, which matters under GDPR.
